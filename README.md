# Java Student Lottery Selector

A console application to manage a list of students and perform random selections.

## Features
- Add/Remove students dynamically
- Draw one by one (removing drawn names)
- Single draw with probability of repeats
- Display current list

## How to Run
1. Ensure you have Java installed (`java` and `javac`).
2. Navigate to the project root:
   ```bash
  cd path/to/project
javac select/*.java
java select.Select
